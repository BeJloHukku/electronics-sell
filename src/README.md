# Процедурная реализация

Python 3.14

Команды выполняются из корня репозитория:

```sh
python3 src/main.py --list
python3 src/main.py --request-id 101
python3 src/main.py --show 101
```

Запуск без аргументов показывает список заявок. Пути к данным определяются
от расположения программы, поэтому можно запускать и из `src`: `python3 main.py`.
Обработка `--request-id` сохраняет решение и изменения склада в JSON.
`--show` и `--list` только читают данные.

## Хранилище

В `storage/data.json` находятся 14 списков с атрибутами логической модели:
`clients`, `emails`, `phone_numbers`, `addresses`, `requests`, `request_items`,
`products`, `prices`, `stocks`, `orders`, `order_items`, `reservations`,
`check_types`, `check_results`. Новые заявки можно добавлять в этот файл вручную
при остановленной программе. Существующие идентификаторы должны быть уникальны.

## Пример запуска

В исходном JSON заявка 101 содержит одну стиральную машину X1 по 49 990 руб. и два
электрочайника B2 по 7 490 руб. Доступны 3 стиральные машины и 5 электрочайников.
На неизмененных исходных данных:

```sh
python3 src/main.py --request-id 101
```

Ожидаемый вывод:

```text
Заявка: 101
Статус: Подтвержден
Заказ: 1
Сумма: 64 970,00 руб.
Весь состав заказа зарезервирован.
```

Остатки стиральных машин и электрочайников станут 2 и 3, появятся две записи резерва.
Повторный запуск выдаст тот же результат и сохранит эти остатки.
Заявка 102 демонстрирует нехватку холодильников, 103 – отсутствие фамилии и контакта.
